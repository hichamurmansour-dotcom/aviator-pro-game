# 🎮 محاكي طيران Aviator Pro

لعبة محاكاة طيران تفاعلية مع تأثيرات بصرية وصوتية متقدمة.

## ✨ الميزات

- **لعب سلس وسريع** - محاكاة فيزياء واقعية للطائرة
- **تأثيرات بصرية** - ذيل ناري وجزيئات دخان ديناميكية
- **تأثيرات صوتية** - أصوات فوز وانفجار واقعية باستخدام Web Audio API
- **سحب آلي** - خيار للسحب التلقائي عند مضاعف معين
- **سجل تاريخي** - تتبع آخر 7 جولات
- **تصميم ريسبونسيف** - يعمل على جميع الأجهزة
- **واجهة عربية** - دعم كامل للغة العربية (RTL)

## 🛠️ البنية المعمارية

تم إعادة هيكلة الكود إلى ملفات منظمة:

```
├── index.html           # ملف HTML الرئيسي
├── styles.css           # الأنماط والتصميم
├── js/
│   ├── particle.js      # فئة الجزيئات
│   ├── audio.js         # مدير الصوت
│   ├── renderer.js      # مدير الرسم
│   ├── gameState.js     # إدارة حالة اللعبة
│   └── game.js          # فئة اللعبة الرئيسية
└── README.md            # هذا الملف
```

## 📝 وصف الملفات

### `index.html`
ملف HTML الرئيسي يحتوي على:
- هيكل الصفحة
- عناصر واجهة المستخدم
- تحميل جميع ملفات JavaScript

### `styles.css`
يتضمن:
- أنماط عامة وتخطيطات
- تنسيق الأزرار والمدخلات
- تأثيرات الرسوم المتحركة
- دعم الشاشات الصغيرة (Responsive)

### `js/particle.js`
فئة `Particle` التي تمثل جزيئات النار والدخان:
- تحديث الموضع والحجم والشفافية
- رسم الجزيئات على Canvas
- التحقق من ما إذا كان الجزيء لا يزال مرئياً

### `js/audio.js`
فئة `AudioManager` تدير التأثيرات الصوتية:
- `playWinSound()` - صوت الفوز
- `playCrashSound()` - صوت الانفجار

### `js/renderer.js`
فئة `GameRenderer` تدير الرسم على Canvas:
- تحميل وإدارة صورة الطائرة
- حساب نقاط المنحنى
- إدارة الجزيئات
- رسم المشهد الكامل

### `js/gameState.js`
فئة `GameState` تدير حالة اللعبة:
- متغيرات الحالة (الرصيد، المضاعف، إلخ)
- العمليات على الحالة (الخصم، الإضافة، إلخ)

### `js/game.js`
فئة `AviatorGame` - المنطق الرئيسي للعبة:
- معالجة المدخلات
- إدارة حلقة اللعبة
- تحديث الواجهة

## 🚀 كيفية الاستخدام

1. افتح `index.html` في متصفح حديث
2. أدخل مبلغ الرهان
3. (اختياري) أدخل قيمة السحب الآلي
4. اضغط "إبدأ الجولة"
5. اضغط "سحب الأرباح" قبل انفجار الطائرة
